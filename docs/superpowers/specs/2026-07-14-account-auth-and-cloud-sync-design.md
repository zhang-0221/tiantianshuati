# 账号登录与云端学习数据同步设计

## 目标

为喜刷刷增加自助注册的账号体系。用户通过“用户名 + 密码”登录，绑定邮箱用于验证和找回密码；题库、答题记录、背诵进度、思维导图和学习设置都归属于账号，可在不同设备恢复。DeepSeek API Key 继续仅保存在用户本机，绝不上传。

## 范围

本期包含：注册、登录、退出、邮箱验证、忘记/重置密码、账号数据首次迁移、云端自动同步、同步状态与失败重试。

本期不包含：社交登录、手机号登录、团队账号、付费订阅、多人协作、云端保存 API Key。

## 用户流程

1. 未登录用户打开站点时进入登录落地页。
2. 新用户填写用户名、密码和邮箱，注册后完成邮箱验证。
3. 已验证用户使用用户名和密码登录；界面不要求用户以邮箱作为登录名。
4. 首次登录若本机有学习数据，提示上传至当前账号；若云端已存在数据，提供“保留云端数据”或“合并本机数据”两个明确选项。
5. 后续学习数据先写入本机缓存，再在网络可用时异步同步云端；同步失败会保留本机数据并可重试。
6. 用户退出后返回登录页；不同账号在同一浏览器中不能看到彼此的数据。

## 登录页视觉

- 使用用户提供的山湖插画作为全屏背景，采用 `cover` 裁切。
- 左上角展示“喜刷刷”品牌标识。
- 桌面端在右侧偏下放置半透明白色、圆角玻璃质感的登录卡，避免遮挡山景主体。
- 卡片仅包含用户名、密码、登录按钮、注册入口和忘记密码入口。
- 移动端将登录卡置于底部并扩展至安全可读宽度，保持背景可见且不影响输入。
- 登录成功后进入现有学习主页；未登录始终保留在登录页。

## 技术架构

- GitHub Pages 继续托管现有静态前端。
- Supabase 提供 Auth、Postgres 数据库、行级安全策略与邮箱验证/密码重置能力。
- Vercel API 提供用户名到账号身份的安全映射，以及不应暴露给浏览器的服务端操作。
- 浏览器使用 Supabase 会话令牌访问只属于当前用户的数据；所有云端表均以 `user_id` 为归属与访问边界。

## 数据模型

### `profiles`

- `id`：关联认证用户 ID。
- `username`：规范化后唯一、不可重复的登录名。
- `email`：用于验证与找回密码。
- `created_at`、`updated_at`。

### `learning_snapshots`

- `user_id`：数据所有者。
- `library`：题库、题目、作答记录和进度的 JSON 数据。
- `settings`：可同步的学习设置 JSON 数据。
- `updated_at`：用于显示同步时间和冲突判断。

数据均启用行级安全：仅当前认证用户可读取或写入自己 `user_id` 的记录。

## 安全与隐私

- 密码由 Supabase Auth 安全哈希保存，项目代码、数据库和浏览器本地存储都不保存明文密码。
- 用户名登录由受保护的服务端接口完成；不向浏览器公开账号邮箱或数据库服务密钥。
- 注册、登录、找回密码接口实施频率限制，并对错误密码返回通用提示。
- DeepSeek API Key 只保留在当前设备的浏览器本地存储，不参与云同步。
- 首次迁移与数据合并必须由用户明确确认，绝不静默覆盖云端数据。

## 异常处理

- 用户名已存在：提示更换用户名。
- 邮箱已存在：提示登录或找回密码，不透露更多账号信息。
- 邮箱未验证：提示重新发送验证邮件。
- 网络离线：本地继续可用，界面显示“待同步”；联网后自动重试。
- 云端冲突：以云端版本为默认安全选项，并提供用户可见的“合并本机数据”选择。
- 同步失败：不清除本机缓存，保留重试入口和失败原因。

## 验收标准

1. 用户可注册唯一用户名、验证邮箱并以用户名密码登录。
2. 错误密码、重复用户名、未验证邮箱与找回密码均有清晰、非泄露性的反馈。
3. 两个账号在同一设备登录时，题库和进度严格隔离。
4. 在另一设备登录同一账号后，可恢复已同步的题库、答题记录、背诵进度、思维导图和学习设置。
5. 本机旧数据首次迁移不会在未确认情况下覆盖云端数据。
6. 断网期间学习数据不丢失，恢复网络后能完成同步。
7. API Key 不会出现在云端数据、接口响应或数据库记录中。
8. 登录页符合确认的山湖背景与玻璃登录卡视觉，并在手机端可用。

## 部署与成本

第一版使用 Supabase Free 与 Vercel Hobby，适合个人和小规模试用。Supabase 免费项目若一周无访问会暂停；Vercel Hobby 仅限个人、非商业用途。上线前需创建 Supabase 项目并提供项目 URL、匿名公钥和 Vercel 服务端环境变量配置；服务端密钥不得写入前端或 Git 仓库。
