# 学习页面统一视觉设计

## 目标

保留当前独立、浅蓝色的左侧导航栏，不改变「导入、我的题库、背诵宝地、情景单词、思维导图、API Key」的功能与跳转关系。统一四个学习页面的视觉骨架，让它们呈现为同一学习工作台中的不同模块。

## 范围

本轮只调整页面结构和视觉反馈，不改变本地存储字段、资料导入、题目生成、背诵、单词学习、导图生成或 API 调用逻辑。

## 页面骨架

「我的题库、背诵宝地、情景单词、思维导图」使用同一结构：

1. 页面头部：英文小标签、中文标题、简短说明，以及与当前模块对应的主操作。
2. 数据概览：最多三张紧凑数据卡片，展示已有真实数据；无真实数据时显示 0，不编造进度。
3. 内容区：最近学习、当前任务或模块主列表，保留现有操作入口。
4. 辅助区：周目标、学习提示或模块说明。桌面端放在主内容右侧；小屏幕自动落到内容区下方。
5. 空状态：用清晰说明和一个唯一主操作引导用户进入下一步，不增加新功能。

## 视觉规范

- 左侧栏继续作为独立的浅蓝圆角面板，使用原有 emoji 图标和白色激活态。
- 内容区使用白色圆角工作面板、低对比边框和浅阴影；保持现有蓝色为主强调色。
- 页面标题突出、说明克制；使用小型英文标签帮助分层，但不替代中文内容。
- 模块卡片有一致的圆角、内边距、标题层级与状态标签。
- 各模块可使用低饱和辅助色区分进度，但主操作始终使用蓝色，避免让用户误判操作优先级。
- 移动端保持左侧导航的现有适配策略；内容区改为单列，关键按钮保持可触达。

## 模块映射

| 模块 | 核心数据 | 主内容 | 主操作 |
| --- | --- | --- | --- |
| 我的题库 | 资料数、完成练习、待复习 | 试卷/资料列表与最近学习 | 导入新资料 |
| 背诵宝地 | 卡片数、今日复习、连续天数 | 今日卡片与背诵列表 | 开始背诵/导入资料 |
| 情景单词 | 单词数、今日掌握、待巩固 | 学习计划与词汇列表 | 开始练习 |
| 思维导图 | 导图数、已覆盖资料、最近更新 | 导图列表与最近导图 | 新建或查看导图 |

## 数据与状态

页面只能读取现有的本地数据与既有渲染结果。已有资料时显示对应统计；缺少数据时将统计展示为 0 并显示相应空状态。加载、生成、成功和失败继续使用既有逻辑，只补充一致的视觉容器和提示文案。

## 验证

- 现有功能回归测试必须全部通过。
- 为共享页面骨架增加静态结构测试，确认四个模块保留现有 ID、事件入口和空状态容器。
- 在桌面端和移动端检查：侧栏、页面头部、卡片换行、主要按钮、空状态和浮动聊天按钮均不重叠。
- 手动检查题库、背诵、单词、导图之间切换后，数据和操作保持原有行为。
