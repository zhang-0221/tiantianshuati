喜刷刷 — 使用说明 & 注意事项
================================

一、怎么获取 API Key（必看）

  1. 打开 https://platform.deepseek.com/api_keys
  2. 注册/登录 DeepSeek 账号（手机号即可）
  3. 点击「创建 API Key」，复制 sk- 开头的那串字符
  4. 打开喜刷刷，点左下角「API Key」，粘贴进去保存

  就这么简单，一分钟搞定。


二、API 要花钱吗？

  API Key 是 DeepSeek 官方的，费用是 DeepSeek 收的，跟喜刷刷没关系。

  喜刷刷本身完全免费，只是个工具。你花的钱是交给 DeepSeek 的——
  就像买了手机，打电话的话费是交给运营商的，不是手机厂商收的。

  费用参考：DeepSeek 目前定价很低，生成一份试卷大概消耗几千 tokens，
  折合人民币几分钱到一毛钱左右。新注册通常有免费额度，够你出几十份卷子。


三、出题会不准吗？

  会的，这是正常现象，无法完全避免。

  原因：
  - AI 可能对资料理解有偏差，偶尔生成资料里没有的内容
  - 资料太长或太短，出题质量会受影响
  - 简答/论述题的参考答案只是参考，不能当标准答案

  建议：
  - 资料尽量结构化（分段清晰、知识点明确），出题效果更好
  - 每道题都有解析，做完看一眼，当二次学习
  - 简答和论述需要自己对比参考答案来判断对错


四、其他注意事项

  - API Key 只存在你自己的浏览器里，不会上传任何地方
  - 试卷数据存在浏览器本地，清除浏览器数据会丢失试卷
  - docx 文件依赖网络加载解析器，首次使用需联网
  - 不支持直接上传图片（PDF也暂不支持），可以先转成 txt 再导入
  - 如果出题失败，检查：网络是否通畅、API Key 是否正确、余额是否充足


五、离线版

  如果没有 API Key 或不想联网，可以用 backup 文件夹里的
  「机考复习工具-本地版.html」，纯本地正则解析出题，功能简化但完全离线。
